## 概述

本文档详细说明 X5 智能视觉解决方案中使用的各类 AI 模型和算法，包括模型架构、输入输出规格、应用场景和配置参数。

### 技术架构

```
输入图像 → 金字塔处理 → 模型推理 → 后处理 → 跟踪 → 行为识别 → 结果输出
```

### 支持的应用场景

| 场景分类 | 具体项目 | 使用模型 |
|---------|---------|---------|
| 人体检测 | 通用人体检测 | YOLOv8 Pose |

## 核心模型

### 1. YOLOv8 Pose（人体姿态检测）

#### 模型信息
- **模型名称**: `yolov8s_pose_640x384_nv12`
- **模型类型**: 单阶段姿态估计
- **输入尺寸**: 640×384 (NV12格式)
- **输出内容**: 人体边界框 + 17个关键点
- **BPU核心**: 1

#### 关键点定义（COCO 17点）
```
0:  鼻子 (Nose)
1:  左眼 (Left Eye)
2:  右眼 (Right Eye)
3:  左耳 (Left Ear)
4:  右耳 (Right Ear)
5:  左肩 (Left Shoulder)
6:  右肩 (Right Shoulder)
7:  左肘 (Left Elbow)
8:  右肘 (Right Elbow)
9:  左手腕 (Left Wrist)
10: 右手腕 (Right Wrist)
11: 左髋 (Left Hip)
12: 右髋 (Right Hip)
13: 左膝 (Left Knee)
14: 右膝 (Right Knee)
15: 左踝 (Left Ankle)
16: 右踝 (Right Ankle)
```

#### 配置参数
```json
{
  "model_file_path": "../../models/yolov8s_pose_640x384_nv12.bin",
  "pyramid_layer": 8,
  "image_input_width": 640,
  "image_input_height": 360,
  "conf_threshold": 0.3,
  "nms_threshold": 0.45,
  "point_threshold": 0.2,
  "min_obj_h": 25.0,
  "min_obj_w": 25.0
}
```

#### 预处理流程
1. 从金字塔第8层获取图像（360×640）
2. 调整尺寸到 640×360
3. Padding 到 640×384
4. NV12 格式输入模型

#### 后处理流程
1. 解析检测框和置信度
2. NMS 去除重复框
3. 关键点坐标解码
4. 坐标映射回原图尺寸
5. 置信度过滤

#### 应用场景
- 基础人体检测与姿态估计
- 实时动作识别
- 人体跟踪
- 体育动作分析

## 体育项目配置

### 1. 跳绳计数

#### 使用模型
- **主模型**: YOLOv8 Pose
- **跟踪**: ByteTrack/IOUTracker
- **行为识别**: SkipRopeEvent

#### 算法流程
```
1. 人体姿态检测（17个关键点）
2. 人体跟踪（分配track_id）
3. 提取关键点序列
   - 左脚踝 (15)
   - 右脚踝 (16)
   - 左手腕 (9)
   - 右手腕 (10)
4. 计算跳跃状态
   - 起跳: 双脚离地（脚踝Y坐标上升）
   - 落地: 双脚着地（脚踝Y坐标下降）
5. 状态机判断
   - IDLE → JUMPING → LANDED → IDLE
6. 计数更新
   - 检测到完整的跳跃周期，计数+1
```

#### 关键参数
```json
{
  "behavior_type": "skip_rope",
  "min_jump_height": 30,        // 最小跳跃高度（像素）
  "max_jump_duration": 1000,    // 最大跳跃持续时间（ms）
  "min_ground_duration": 100,   // 最小着地时间（ms）
  "foot_threshold": 0.5,        // 脚部关键点置信度阈值
  "hand_threshold": 0.5         // 手部关键点置信度阈值
}
```

#### 配置文件
- `item_kps_configs/skip_rope_solution.json`

### 2. 俯卧撑计数

#### 使用模型
- **主模型**: YOLOv8 Pose
- **跟踪**: IOUTracker
- **行为识别**: PushUpEvent

#### 算法流程
```
1. 人体姿态检测
2. 提取关键特征
   - 肘关节角度
   - 肩关节角度
   - 身体水平角度
3. 状态判断
   - DOWN: 身体下降，肘关节弯曲（<90°）
   - UP: 身体上升，肘关节伸直（>160°）
4. 动作标准性判断
   - 身体保持水平
   - 肘关节弯曲角度达标
   - 动作幅度达标
5. 计数和评分
   - 标准动作: +1分
   - 不标准动作: +0.5分或不计数
```

#### 关键点计算
```cpp
// 肘关节角度计算
float elbow_angle = ComputeAngle(
    shoulder,  // 关键点 5 或 6
    elbow,     // 关键点 7 或 8
    wrist      // 关键点 9 或 10
);

// 身体水平角度
float body_angle = ComputeAngle(
    shoulder,  // 肩膀
    hip,       // 髋部（11或12）
    ankle      // 脚踝（15或16）
);
```

### 6. 篮球运球

#### 使用模型
- **人体模型**: YOLOv8 Pose
- **目标检测**: YOLOv8 Object (Basketball)
- **行为识别**: DribbleEvent

#### 算法流程
```
1. 人体姿态检测
2. 篮球目标检测
3. 人球关联
   - 计算手部与球的距离
   - 判断球是否在控制范围内
4. 运球动作识别
   - 手臂挥动频率
   - 球的位置变化
   - 运球节奏
5. 运球次数统计
   - 检测球的上下运动
   - 手部接触球
   - 完整运球周期
```

#### 人球匹配算法
```cpp
// 计算手部中心到球的距离
float CalculateHandBallDistance(
    Point hand_left,    // 左手腕
    Point hand_right,   // 右手腕
    Point ball_center   // 球心
) {
    Point hand_center = (hand_left + hand_right) / 2;
    float distance = EuclideanDistance(hand_center, ball_center);
    return distance;
}

// 判断球是否被控制
bool IsBallControlled(float distance, float threshold = 150) {
    return distance < threshold;
}
```

#### 脚球距离计算
```cpp
// 计算最近的脚到球的距离
float CalculateFootBallDistance(
    Point left_ankle,   // 左脚踝
    Point right_ankle,  // 右脚踝
    Point ball_center   // 球心
) {
    float dist_left = EuclideanDistance(left_ankle, ball_center);
    float dist_right = EuclideanDistance(right_ankle, ball_center);
    return std::min(dist_left, dist_right);
}
```

## 算法流程

### 1. ByteTrack 跟踪算法

#### 算法原理
ByteTrack 是一种简单高效的多目标跟踪算法，主要特点：
- 同时使用高分和低分检测框
- 通过卡尔曼滤波预测位置
- 两阶段匹配策略

#### 流程图
```
输入: 当前帧检测框列表

1. 分离高分和低分检测框
   high_boxes = boxes[score > high_thresh]
   low_boxes = boxes[low_thresh < score < high_thresh]

2. 第一阶段匹配（高分框与跟踪器）
   matches_1, unmatched_tracks, unmatched_high = 
       LinearAssignment(tracks, high_boxes, match_thresh)

3. 第二阶段匹配（低分框与未匹配跟踪器）
   matches_2, unmatched_tracks, unmatched_low = 
       LinearAssignment(unmatched_tracks, low_boxes, match_thresh)

4. 更新跟踪器
   - 匹配成功的跟踪器更新
   - 未匹配的跟踪器标记为lost
   - 新检测框创建新跟踪器

5. 删除长时间丢失的跟踪器

输出: 跟踪结果（track_id + bbox）
```

#### 配置参数
```json
{
  "track_thresh": 0.6,       // 跟踪置信度阈值
  "high_thresh": 0.6,        // 高分检测框阈值
  "match_thresh": 0.8,       // 匹配IOU阈值
  "min_box_area": 100,       // 最小框面积
  "frame_rate": 30,          // 帧率
  "track_buffer": 30         // 跟踪缓冲帧数
}
```

### 2. IOU Tracker 跟踪算法

#### 算法原理
基于IOU（Intersection over Union）的简单跟踪算法：
- 计算检测框与跟踪框的IOU
- 基于IOU进行匹配
- 匈牙利算法分配

#### 流程图
```
输入: 当前帧检测框

1. 预测跟踪框位置
   predicted_boxes = KalmanFilter.predict(tracks)

2. 计算IOU矩阵
   iou_matrix = ComputeIOU(predicted_boxes, detected_boxes)

3. 匈牙利匹配
   matches = HungarianAlgorithm(iou_matrix, threshold)

4. 更新跟踪器
   for match in matches:
       tracks[match.track_id].update(match.detection)

5. 处理未匹配
   - 未匹配跟踪器: age++
   - 未匹配检测框: 创建新跟踪器

6. 删除老化跟踪器
   tracks = RemoveOldTracks(tracks, max_age)

输出: 跟踪结果
```

#### 配置参数
```json
{
  "iou_threshold": 0.3,      // IOU匹配阈值
  "max_age": 30,             // 最大跟踪年龄
  "min_hits": 3,             // 最小命中次数
  "use_kalman": true         // 是否使用卡尔曼滤波
}
```

### 4. 行为状态机

#### 状态机架构
```cpp
class BehaviorStateMachine {
public:
    enum State {
        IDLE,       // 空闲
        READY,      // 准备
        ACTIVE,     // 激活
        COMPLETE,   // 完成
        ERROR       // 错误
    };
    
    State current_state;
    
    void Update(const Features& features) {
        switch (current_state) {
            case IDLE:
                if (CheckReadyCondition(features)) {
                    current_state = READY;
                }
                break;
            case READY:
                if (CheckActiveCondition(features)) {
                    current_state = ACTIVE;
                    action_count++;
                }
                break;
            case ACTIVE:
                if (CheckCompleteCondition(features)) {
                    current_state = COMPLETE;
                }
                break;
            case COMPLETE:
                current_state = IDLE;
                break;
        }
    }
};
```

```cpp
float CalculateScore(const Action& action) {
    float score = 100.0f;
    
    // 角度准确度
    float angle_error = abs(action.angle - standard_angle);
    score -= angle_error * angle_weight;
    
    // 幅度达标
    if (action.amplitude < min_amplitude) {
        score -= 20.0f;
    }
    
    // 持续时间
    if (action.duration < min_duration) {
        score -= 10.0f;
    }
    
    // 稳定性
    score -= action.shake * shake_weight;
    
    return max(0.0f, score);
}
```
