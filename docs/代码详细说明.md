## 项目概述

### 1.1 项目简介
本项目是基于地平线 X5/X3 芯片平台的智能视觉解决方案，主要应用于体育运动场景的人体检测、姿态识别、行为分析等智能视觉任务。该方案集成了完整的从图像采集到智能结果输出的全流程处理能力。

### 1.2 主要特性
- **多平台支持**：支持 X3 和 X5 两种地平线芯片平台
- **模块化架构**：基于 XStream 和 XProto 框架的插件式架构
- **多种输入源**：支持 MIPI 摄像头、RTSP 视频流、USB 摄像头等
- **丰富的 AI 能力**：
  - 人体检测与跟踪
  - 人体姿态估计（17点/25点关键点）
  - 人脸检测与识别
  - 手部关键点检测
  - 目标检测与跟踪
  - 行为识别（跳绳、深蹲、俯卧撑等体育动作）
  - OCR 文字识别
- **多种输出方式**：WebSocket、RTSP、HTTP、MQTT 等
- **高性能**：支持 BPU 硬件加速，60fps 实时处理

### 1.3 应用场景
- 智慧体育：跳绳计数、体育测试、动作评分
- 智慧校园：学生行为分析、体育考试
- 健身场景：动作识别与纠正
- 安防监控：人体检测与跟踪

### 1.4 技术栈
- **编程语言**：C++14/17
- **AI 框架**：地平线 DNN/BPU 推理引擎
- **通信协议**：WebSocket, MQTT, RTSP, HTTP
- **图像处理**：OpenCV, libyuv, libjpeg-turbo
- **构建工具**：CMake 3.0+
- **交叉编译**：ARM GNU Toolchain

### 2.2 核心组件关系

#### XStream Framework（数据流框架）
- **功能**：提供基于数据流的 SDK 编程框架
- **核心概念**：
  - **Workflow**：有向拓扑图，定义能力的串联方式
  - **Method**：具体的算法能力（检测、跟踪、识别等）
  - **Node**：管理 Method 实例的节点
  - **Scheduler**：统一调度各个 Node 的依赖引擎

#### XProto Framework（插件管理框架）
- **功能**：插件管理和消息订阅分发
- **特点**：
  - 所有插件连接到消息总线
  - 消息驱动的异步处理
  - 支持消息订阅和发布

## 核心框架

### 3.1 XStream Framework（工作流框架）

#### 3.1.1 XStream 核心概念

**Workflow（工作流）**
- 一个有向拓扑图，定义了算法能力的串联方式
- 通过 JSON 配置文件定义
- 支持单路和多路输出

**Method（方法）**
- 代表一种算法能力
- 类型：
  - 模型能力：人脸检测、姿态估计等
  - 算法策略：过滤、融合、优选等
- 通过继承 `Method` 基类实现

**Node（节点）**
- 管理一个或多个同类型的 Method 实例
- 负责任务分发与后处理
- 支持多线程并发处理

**Scheduler（调度器）**
- 记录 Node 之间的依赖关系
- 统一调度各个 Node
- 确保按序完成 Workflow 任务

#### 3.1.2 XStream SDK 接口

```cpp
// 创建 SDK 实例
XStreamSDK* sdk = XStreamSDK::CreateSDK();

// 配置
sdk->SetConfig("config_file", "workflow.json");
sdk->SetConfig("profiler", "on");  // 性能统计

// 初始化
sdk->Init();

// 同步预测
InputDataPtr input = ...;
OutputDataPtr output = sdk->SyncPredict(input);

// 异步预测
sdk->SetCallback(callback_func);
sdk->AsyncPredict(input);
```

### 3.2 XProto Framework（插件框架）

#### 3.2.1 XProto 核心概念

**Plugin（插件）**
- 代表一个功能模块
- 可以订阅和发布消息
- 基类：`XPlugin` 和 `XPluginAsync`

**Message（消息）**
- 插件之间通信的载体
- 继承自 `XProtoMessage`
- 通过消息总线传递

**MessageBus（消息总线）**
- 连接所有插件
- 负责消息分发
- 支持订阅发布模式

#### 3.2.2 插件开发示例

```cpp
class MyPlugin : public XPluginAsync {
 public:
  int Init() override {
    // 订阅消息
    RegisterMsg("VioMessage", 
                std::bind(&MyPlugin::OnVioMessage, this, 
                         std::placeholders::_1));
    return XPluginAsync::Init();
  }

  int OnVioMessage(XProtoMessagePtr msg) {
    // 处理消息
    auto vio_msg = std::static_pointer_cast<VioMessage>(msg);
    
    // 处理完成后发布新消息
    auto smart_msg = std::make_shared<SmartMessage>();
    PushMsg(smart_msg);
    
    return 0;
  }
};
```

## 核心模块详解

### 6.1 主程序 (main.cpp)

#### 6.1.1 程序启动流程

```cpp
int main(int argc, char **argv) {
    // 1. 参数解析
    // 必需参数：
    //   argv[1]: VIO 配置文件
    //   argv[2]: XStream 配置文件
    //   argv[3]: Visual 配置文件
    //   argv[4]: 日志级别 (-i/-d/-w/-e/-f)
    //   argv[5]: 运行模式 (可选)
    
    // 2. 初始化
    syncOldCamCfg();           // 同步旧的摄像头配置
    SetVersion();              // 设置版本信息
    item_secret::init_all_secret(); // 初始化加密
    
    // 3. 创建插件
    // 3.1 输入插件（二选一）
    if (use_rtsp) {
        // RTSP 视频流输入
        auto rtsp_plg = std::make_shared<rtspPlugin>();
    } else {
        // MIPI 摄像头输入
        auto mipi_cam = std::make_shared<MipiCamPlugin>();
    }
    
    // 3.2 智能处理插件
    auto smart_plg = std::make_shared<SmartPlugin>();
    
    // 3.3 输出插件
    if (display_mode == 1) {
        // WebSocket 输出
        auto ws_plg = std::make_shared<WebsocketPlugin>();
    }
    
    // 3.4 辅助插件
    auto http_server = new HttpSever_t(9551, ws_plg);
    auto mqtt_client = new MQTTClient_m();
    auto mc_plugin = std::make_shared<MCPlugin>();
    auto sport_plugin = std::make_shared<SportPlugin>();
    
    // 4. 初始化和启动所有插件
    for (auto& plugin : plugins) {
        plugin->Init();
        plugin->Start();
    }
    
    // 5. 等待退出信号
    while (!PluginContext::Instance().exit) {
        std::this_thread::sleep_for(std::chrono::milliseconds(500));
    }
    
    // 6. 清理资源
    for (auto& plugin : plugins) {
        plugin->Stop();
        plugin->DeInit();
    }
    
    return 0;
}
```

### 6.2 SmartPlugin（智能处理插件）

#### 功能
- 管理 XStream Workflow
- 处理图像输入
- 执行 AI 推理
- 发布智能结果

#### 核心流程

```cpp
class SmartPlugin : public XPluginAsync {
  // 初始化
  int Init() {
    // 加载 workflow 配置
    sdk_ = XStreamSDK::CreateSDK();
    sdk_->SetConfig("config_file", smart_config_file);
    sdk_->Init();
    
    // 订阅图像消息
    RegisterMsg("VioMessage", 
                std::bind(&SmartPlugin::OnVioMessage, ...));
    
    return XPluginAsync::Init();
  }
  
  // 处理图像消息
  int OnVioMessage(XProtoMessagePtr msg) {
    auto vio_msg = std::static_pointer_cast<VioMessage>(msg);
    
    // 构建 XStream 输入
    InputDataPtr input = CreateInput(vio_msg);
    
    // 异步预测
    sdk_->AsyncPredict(input);
    
    return 0;
  }
  
  // 预测结果回调
  void OnCallback(OutputDataPtr output) {
    // 解析智能结果
    auto smart_msg = ParseSmartMessage(output);
    
    // 发布智能消息
    PushMsg(smart_msg);
  }
};
```

#### 8.2.1 实现 Plugin 类

```cpp
#include "xproto/plugin/xpluginasync.h"

class MyPlugin : public XPluginAsync {
 public:
  MyPlugin() = default;
  ~MyPlugin() override = default;

  int Init() override {
    // 1. 加载配置
    LoadConfig();
    
    // 2. 订阅消息
    RegisterMsg("InputMessage",
                std::bind(&MyPlugin::OnInputMessage, this,
                         std::placeholders::_1));
    
    // 3. 初始化资源
    InitResources();
    
    // 4. 调用父类 Init
    return XPluginAsync::Init();
  }

  int Start() override {
    // 启动插件
    running_ = true;
    worker_thread_ = std::thread(&MyPlugin::WorkLoop, this);
    return 0;
  }

  int Stop() override {
    // 停止插件
    running_ = false;
    if (worker_thread_.joinable()) {
      worker_thread_.join();
    }
    return 0;
  }

  int DeInit() override {
    // 清理资源
    ReleaseResources();
    return XPluginAsync::DeInit();
  }

  std::string desc() const override {
    return "MyPlugin";
  }

 private:
  int OnInputMessage(XProtoMessagePtr msg) {
    // 1. 转换消息类型
    auto input_msg = std::static_pointer_cast<InputMessage>(msg);
    
    // 2. 处理消息
    auto result = ProcessMessage(input_msg);
    
    // 3. 发布输出消息
    auto output_msg = std::make_shared<OutputMessage>();
    output_msg->data = result;
    PushMsg(output_msg);
    
    return 0;
  }

  void WorkLoop() {
    while (running_) {
      // 执行周期性任务
      DoPeriodicWork();
      std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
  }

  bool running_ = false;
  std::thread worker_thread_;
};
```

### 8.4 添加新的体育项目

#### 8.4.1 创建新的 Behavior Event

```cpp
#include "BehaviorMethod/BehaviorEvent.h"

class MyNewSportEvent : public BehaviorEvent {
 public:
  MyNewSportEvent() : BehaviorEvent() {
    behavior_type_ = "my_new_sport";
  }

  void GetEventInfo(
      std::map<int, std::shared_ptr<BehaviorInfo>>& behavior_info,
      std::map<int, std::shared_ptr<SkeletonInfo>>& skeleton_info,
      const std::shared_ptr<EventParameter>& event_parameter) override {
    
    // 遍历每个跟踪 ID
    for (auto& item : skeleton_info) {
      int track_id = item.first;
      auto& skel_info = item.second;
      
      // 获取关键点
      auto& keypoints = skel_info->keypoints;
      
      // 计算关节角度或其他特征
      float angle = CalculateAngle(keypoints);
      
      // 状态机逻辑
      auto& behavior = behavior_info[track_id];
      if (!behavior) {
        behavior = std::make_shared<BehaviorInfo>();
        behavior->track_id = track_id;
      }
      
      // 判断状态转换
      if (IsStartState(angle)) {
        behavior->state = STATE_START;
        behavior->start_time = current_time_;
      } else if (IsEndState(angle) && behavior->state == STATE_START) {
        behavior->state = STATE_END;
        behavior->count++;  // 计数加一
        
        // 计算评分
        float score = CalculateScore(behavior);
        behavior->score = score;
      }
    }
  }

 private:
  enum State {
    STATE_IDLE,
    STATE_START,
    STATE_END
  };
  
  float CalculateAngle(const std::vector<Point>& keypoints) {
    // 计算关节角度
    // 例如：肘关节角度
    auto shoulder = keypoints[5];  // 肩膀
    auto elbow = keypoints[7];     // 肘部
    auto wrist = keypoints[9];     // 手腕
    
    float angle = ComputeAngle(shoulder, elbow, wrist);
    return angle;
  }
  
  bool IsStartState(float angle) {
    // 判断是否进入开始状态
    return angle > 160.0f;
  }
  
  bool IsEndState(float angle) {
    // 判断是否进入结束状态
    return angle < 90.0f;
  }
  
  float CalculateScore(const std::shared_ptr<BehaviorInfo>& behavior) {
    // 根据动作质量计算评分
    float duration = current_time_ - behavior->start_time;
    float score = 100.0f;
    
    // 根据持续时间调整分数
    if (duration < min_duration_) {
      score -= 20.0f;
    }
    
    return score;
  }
  
  float min_duration_ = 0.5f;  // 最小持续时间
};
```

```cpp
class MyModelPostProcess : public PostProcess {
 public:
  int Init(const std::string &json_str) override {
    Json::Value config;
    Json::Reader reader;
    reader.parse(json_str, config);
    
    score_threshold_ = config["score_threshold"].asFloat();
    nms_threshold_ = config["nms_threshold"].asFloat();
    
    return 0;
  }

  int Execute(
      const std::vector<std::shared_ptr<InferenceEngineTask>> &tasks,
      std::vector<xstream::BaseDataPtr> *frame_result) override {
    
    for (auto& task : tasks) {
      // 获取输出 tensor
      auto& outputs = task->output_tensors_;
      
      // 解析模型输出
      std::vector<Detection> detections;
      ParseModelOutput(outputs, detections);
      
      // NMS
      std::vector<Detection> nms_results;
      ApplyNMS(detections, nms_results);
      
      // 转换为框架数据类型
      auto result = ConvertToBaseData(nms_results);
      frame_result->push_back(result);
    }
    
    return 0;
  }

 private:
  void ParseModelOutput(
      const std::vector<Tensor>& outputs,
      std::vector<Detection>& detections) {
    // 根据模型输出格式解析
    // 例如: [batch, num_boxes, 5+num_classes]
    float* data = reinterpret_cast<float*>(outputs[0].data);
    
    for (int i = 0; i < num_boxes; i++) {
      float score = data[i * stride + 4];
      if (score > score_threshold_) {
        Detection det;
        det.x1 = data[i * stride + 0];
        det.y1 = data[i * stride + 1];
        det.x2 = data[i * stride + 2];
        det.y2 = data[i * stride + 3];
        det.score = score;
        det.class_id = GetClassId(&data[i * stride + 5]);
        
        detections.push_back(det);
      }
    }
  }
  
  float score_threshold_;
  float nms_threshold_;
};
```

   - 减少推理次数
