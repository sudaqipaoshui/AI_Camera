## 核心算法

### 1. 圈数计算算法

#### 算法原理

长跑圈数统计基于**几何距离计算**，通过监测运动员相对起点线的距离变化来判断是否完成一圈。

#### 核心思路

```
起点线位置: (x1, y1) → (x2, y2)
运动员位置: 脚踝中点 (ankle_x, ankle_y)

1. 计算运动员到起点线的垂直距离 d
2. 当 d 从大变小（跨越起点线），圈数 +1
3. 记录每圈的时间和速度
```

#### 详细算法流程

```cpp
// 圈数计算主流程
void AdvanceRun(FrameMessage& frame) {
    for (auto& runner : active_runners) {
        // 步骤1: 获取运动员当前位置（脚踝中点）
        cv::Point2f ankle_mid = GetMidAnkle(runner.landmarks);
        
        // 步骤2: 计算到起点线的距离
        float current_dist = CalculateDistanceToLine(ankle_mid, start_line);
        
        // 步骤3: 第一次记录（基准点）
        if (runner.first_dist == 0) {
            runner.first_dist = current_dist;
            runner.first_dist_time = GetCurrentTime();
            LOGI << "运动员 " << runner.id << " 首次记录距离: " << current_dist;
        }
        
        // 步骤4: 更新最后距离
        runner.last_dist = current_dist;
        runner.last_dist_time = GetCurrentTime();
        
        // 步骤5: 检测过线（完成一圈）
        // 条件: 第一次距离 > 半圈长 && 当前距离 < 半圈长
        // 说明: 运动员已经绕了一圈回到起点线
        if (runner.first_dist > cycle_size / 2 && 
            current_dist < cycle_size / 2) {
            
            // 圈数 +1
            runner.lap_count++;
            
            // 计算本圈用时（秒）
            int64_t lap_time_ms = runner.last_dist_time - runner.first_dist_time;
            float lap_time_sec = lap_time_ms / 1000.0f;
            runner.lap_speeds.push_back(lap_time_sec);
            
            LOGW << "运动员 " << runner.id 
                 << " 完成第 " << runner.lap_count << " 圈"
                 << ", 用时: " << lap_time_sec << " 秒";
            
            // 重置基准点（开始下一圈）
            runner.first_dist = current_dist;
            runner.first_dist_time = runner.last_dist_time;
        }
        
        // 步骤6: 计算已完成距离
        float completed_distance = runner.lap_count * cycle_size + current_dist;
        runner.completed_distance = completed_distance;
        
        // 步骤7: 判断是否完成比赛
        if (completed_distance >= max_distance) {
            runner.is_cross = true;
            runner.cross_time = GetCurrentTime();
            runner.total_time = (runner.cross_time - start_time) / 1000.0f;
            
            LOGW << "运动员 " << runner.id << " 完成比赛!"
                 << " 总用时: " << runner.total_time << " 秒";
        }
    }
}
```

#### 距离计算详解

**点到直线的距离公式**:

```cpp
float CalculateDistanceToLine(cv::Point2f point, Line line) {
    // 直线方程: Ax + By + C = 0
    // line: (x1,y1) → (x2,y2)
    
    float A = line.y2 - line.y1;
    float B = line.x1 - line.x2;
    float C = line.x2 * line.y1 - line.x1 * line.y2;
    
    // 点到直线距离公式
    float distance = abs(A * point.x + B * point.y + C) / 
                     sqrt(A * A + B * B);
    
    return distance;
}
```

#### 为什么用 `cycle_size / 2` 作为判定条件？

```
跑道示意图:

    起点线
      ↓
  ════╪════
  ║       ║
  ║   d   ║  ← 运动员在跑道另一侧时，距离 > cycle_size/2
  ║       ║
  ════════

运动员跑一圈的距离变化:
1. 起点: d = 0
2. 跑向对面: d 逐渐增大
3. 到达对面: d ≈ cycle_size/2 (最大)
4. 跑回起点: d 逐渐减小
5. 回到起点: d ≈ 0 (完成一圈)

判定逻辑:
- first_dist > cycle_size/2: 说明运动员已经跑到对面
- current_dist < cycle_size/2: 说明运动员正在回来
- 从"大于半圈"变为"小于半圈" = 完成一圈
```

#### 2.1 人脸识别模式 (rec_type = 0)

**流程**:

```cpp
// 人脸识别主流程
void RecognizeFace(cv::Mat& frame, Runner& runner) {
    // 步骤1: 提取人脸特征
    std::vector<float> face_feature = ExtractFaceFeature(
        frame, 
        runner.face_box, 
        runner.face_landmarks
    );
    
    if (face_feature.empty()) {
        return;  // 特征提取失败
    }
    
    // 步骤2: 归一化特征向量
    NormalizeFeature(face_feature);
    
    // 步骤3: 与数据库特征匹配
    float max_similarity = 0.0f;
    std::string best_match_id = "-1";
    
    for (auto& [person_id, db_features] : face_database) {
        for (auto& db_feature : db_features) {
            // 计算余弦相似度
            float similarity = CosineSimilarity(face_feature, db_feature);
            
            if (similarity > max_similarity) {
                max_similarity = similarity;
                best_match_id = person_id;
            }
        }
    }
    
    // 步骤4: 判断是否匹配成功
    if (max_similarity >= new_feature_rec_sim_threshold_v2) {
        runner.person_id = best_match_id;
        runner.is_confirm = true;
        runner.recognition_confidence = max_similarity;
        
        LOGI << "识别成功: ID=" << best_match_id 
             << ", 相似度=" << max_similarity;
    } else {
        // 新面孔，分配新ID
        runner.person_id = GenerateNewID();
        AddToDatabase(runner.person_id, face_feature);
    }
}

// 余弦相似度计算
float CosineSimilarity(const std::vector<float>& v1, 
                      const std::vector<float>& v2) {
    float dot_product = 0.0f;
    float norm_v1 = 0.0f;
    float norm_v2 = 0.0f;
    
    for (size_t i = 0; i < v1.size(); i++) {
        dot_product += v1[i] * v2[i];
        norm_v1 += v1[i] * v1[i];
        norm_v2 += v2[i] * v2[i];
    }
    
    return dot_product / (sqrt(norm_v1) * sqrt(norm_v2));
}
```

```
   ↓
3. 特征提取 (FaceID Model → 128维向量)
   ↓
4. 特征归一化

5. 存入数据库
```

#### 2.2 号码布识别模式 (rec_type = 1)

**流程**:

```cpp
// 号码识别主流程
void RecognizeNumber(cv::Mat& frame, Runner& runner) {
    // 步骤1: 定位号码布区域
    // 通常在身体上部（胸部区域）
    cv::Rect vest_area = GetVestArea(runner.body_box, vest_scale);
    cv::Mat vest_roi = frame(vest_area);
    
    // 步骤2: 检测号码（YOLOv8）
    std::vector<cv::Rect> number_boxes = number_detector.Detect(vest_roi);
    
    if (number_boxes.empty()) {
        return;  // 未检测到号码
    }
    
    // 步骤3: OCR识别号码
    std::string recognized_num = "";
    for (auto& box : number_boxes) {
        cv::Mat number_roi = vest_roi(box);
        std::string num = ocr_recognizer.Recognize(number_roi);
        recognized_num += num;
    }
    
    // 步骤4: 添加到候选列表
    runner.num_infos.push_back({
        .race_num = recognized_num,
        .confidence = 1.0f,
        .timestamp = GetCurrentTime()
    });
    
    // 步骤5: 多帧投票确认
    std::map<std::string, int> vote_count;
    for (auto& info : runner.num_infos) {
        vote_count[info.race_num]++;
    }
    
    // 步骤6: 选择出现次数最多的号码
    for (auto& [num, count] : vote_count) {
        if (count >= num_min_rec_time_v2) {
            runner.race_num = num;
            runner.is_confirm = true;
            
            LOGI << "号码确认: " << num 
                 << ", 识别次数: " << count;
            break;
        }
    }
}

// 获取号码布区域
cv::Rect GetVestArea(cv::Rect body_box, float vest_scale) {
    // 号码布通常在身体上部 30%（胸部位置）
    int vest_height = body_box.height * vest_scale;
    
    cv::Rect vest_area;
    vest_area.x = body_box.x;
    vest_area.y = body_box.y;
    vest_area.width = body_box.width;
    vest_area.height = vest_height;
    
    return vest_area;
}
```

**号码识别流程**:

```
1. 身体检测
   ↓
2. 提取胸部区域 (vest_scale = 0.3)
   ↓
3. YOLOv8 数字检测
   ↓
4. OCR 识别数字
   ↓
5. 多帧投票（至少识别N次）
   ↓
6. 确认号码
```

**为什么需要多帧投票？**

```
问题: OCR识别可能不稳定
- 光照变化
- 角度变化
- 号码布褶皱
- 遮挡

解决方案: 多帧投票
- 连续识别多帧（如10帧）
- 统计每个号码出现的次数
- 选择出现次数最多的号码
- 增强识别准确性和稳定性
```

### 3. 预测完成时间算法

```cpp
// 预测完成时间
float PredictFinishTime(Runner& runner) {
    // 步骤1: 计算已完成距离
    float completed_distance = runner.lap_count * cycle_size + runner.last_dist;
    
    // 步骤2: 计算已用时间（秒）
    int64_t elapsed_time_ms = runner.last_dist_time - start_time;
    float elapsed_time_sec = elapsed_time_ms / 1000.0f;
    
    // 步骤3: 计算平均速度（米/秒）
    float avg_speed = completed_distance / elapsed_time_sec;
    
    // 步骤4: 计算剩余距离
    float remaining_distance = max_distance - completed_distance;
    
    // 步骤5: 预测剩余时间
    float predicted_remaining_time = remaining_distance / avg_speed;
    
    // 步骤6: 预测总完成时间
    float predicted_total_time = elapsed_time_sec + predicted_remaining_time;
    
    LOGD << "预测: 运动员 " << runner.id
         << ", 平均速度: " << avg_speed << " m/s"
         << ", 预计剩余: " << predicted_remaining_time << " 秒"
         << ", 预计总时间: " << predicted_total_time << " 秒";
    
    return predicted_remaining_time;
}
```

**预测示例**:

```
场景: 1000米跑，圈长200米

当前状态:
- 已完成圈数: 3圈
- 当前距离: 50米
- 已完成距离: 3 × 200 + 50 = 650米
- 已用时间: 150秒
- 平均速度: 650 / 150 = 4.33 m/s

预测:
- 剩余距离: 1000 - 650 = 350米
- 预计剩余时间: 350 / 4.33 = 80.8秒
- 预计总时间: 150 + 80.8 = 230.8秒 (≈ 3分51秒)
```

### 4. 实时排名算法

```cpp
// 实时排名
void UpdateRanking() {
    // 步骤1: 按完成距离降序排序
    std::sort(active_runners.begin(), active_runners.end(), 
        [](const Runner& a, const Runner& b) {
            // 已完成的运动员排在前面
            if (a.is_cross != b.is_cross) {
                return a.is_cross > b.is_cross;
            }
            
            // 完成距离更远的排在前面
            if (a.completed_distance != b.completed_distance) {
                return a.completed_distance > b.completed_distance;
            }
            
            // 距离相同，用时更少的排在前面
            return a.total_time < b.total_time;
        }
    );
    
    // 步骤2: 分配排名
    for (size_t i = 0; i < active_runners.size(); i++) {
        active_runners[i].rank = i + 1;
    }
}
```

```cpp
    cycle_size_ = config.get("cycle_size", 200).asFloat();
    rec_type_ = config.get("rec_type", 0).asInt();
    
    // 2. 读取识别参数
    min_track_length_ = config.get("min_track_length", 2).asInt();
    vest_scale_ = config.get("vest_scale", 0.3).asFloat();
    
    // 3. 读取区域配置
    if (config.isMember("init_area")) {
        auto area = config["init_area"];
        for (auto& point : area) {
            start_line_.push_back(cv::Point2f(
                point["x"].asFloat(),
                point["y"].asFloat()
            ));
        }
    }
    
    // 4. 初始化状态
    is_running_ = false;
    start_time_ = 0;
    
    LOGI << "LongRace初始化成功: "
         << "距离=" << max_distance_ 
         << "米, 圈长=" << cycle_size_ << "米";
    
    return 0;
```

#### DoProcess() - 主处理

```cpp
int LongRace::DoProcess(x3::FrameMessage& frame_message) {
    if (!is_running_) {
        return 0;
    }
    
    // 1. 获取当前帧图像
    cv::Mat frame = GetFrameImage(frame_message);
    
    // 2. 创建或更新运动员
    UpdateRunner(frame_message);
    
    // 3. 身份识别
    if (rec_type_ == 0) {
        RecFace(frame, frame_message);      // 人脸识别
    } else if (rec_type_ == 1) {
        RecNum(frame, frame_message);       // 号码识别
    }
    
    // 4. 圈数统计
    AdvanceRun(frame_message);
    
    // 5. 计算成绩
    CalculateResults();
    
    // 6. 更新排名
    UpdateRanking();
    
    // 7. 发送结果
    SendResults();
    
    // 8. 移除不活跃运动员
    RemoveInactiveRunners();
    
    return 0;
}
```

## 常见问题

### Q1: 圈数统计不准确怎么办？

**可能原因**:
1. 起点线位置设置不准确
2. cycle_size 设置错误
3. 运动员位置检测不稳定

**解决方案**:
```
1. 重新校准起点线
   - 确保起点线与实际起跑线对齐
   - 使用标定工具精确设置

2. 验证 cycle_size
   - 实地测量跑道周长
   - 标准田径场: 400米
   - 学校操场: 通常200米或250米

3. 优化检测参数
   - 提高关键点置信度阈值
   - 使用低通滤波平滑位置
```

### Q2: 身份识别失败率高？

**人脸识别问题**:
```
原因:
- 光照不足
- 角度过大
- 遮挡（口罩、帽子）

解决:
1. 增加补光设备
2. 调整相机角度（正面拍摄）
3. 降低相似度阈值（min_rec_sim_threshold: 0.7 → 0.6）
4. 增加识别次数要求
```

**号码识别问题**:
```
原因:
- 号码布皱褶
- 距离过远
- 光线反射

解决:
1. 使用高对比度号码布（黑底白字）
2. 增加 num_min_rec_time_v2（多帧投票）
3. 优化相机位置（近距离拍摄）
4. 使用更高分辨率相机
```

### Q4: 如何优化预测准确性？

```cpp
// 1. 使用加权平均速度（近期圈速权重更高）
float CalculateWeightedSpeed(const std::vector<float>& lap_times) {
    float weighted_sum = 0.0f;
    float weight_sum = 0.0f;
    
    for (int i = 0; i < lap_times.size(); i++) {
        float weight = i + 1;  // 越近的圈，权重越高
        weighted_sum += (cycle_size / lap_times[i]) * weight;
        weight_sum += weight;
    }
    
    return weighted_sum / weight_sum;
}

// 2. 考虑体能下降因子
float PredictWithFatigue(Runner& runner) {
    float avg_speed = CalculateWeightedSpeed(runner.lap_speeds);
    
    // 体能下降系数（后半程速度下降5-10%）
    float fatigue_factor = 0.95;
    if (runner.completed_distance > max_distance_ * 0.5) {
        fatigue_factor = 0.90;
    }
    
    float adjusted_speed = avg_speed * fatigue_factor;
    float remaining_distance = max_distance_ - runner.completed_distance;
    
    return remaining_distance / adjusted_speed;
}
```
