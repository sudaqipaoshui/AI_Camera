## 📝 代码贡献规范

### 添加新运动项目步骤

1. **创建实现类**:
   ```
   sportplugin/include/sportplugin/YourSport.h
   sportplugin/src/sportplugin/YourSport.cpp
   ```

2. **创建行为事件**:
   ```
   behavior_method/include/BehaviorMethod/YourEvent.h
   behavior_method/src/YourEvent.cpp
   ```

3. **添加配置文件**:
   ```
   body/x5/your_configs/
   ├── your_solution.json
   ├── your_workflow.json
   └── your_event.json
   ```

4. **注册项目ID**:
   - 在 `SportInfoSetting.h` 中添加ID映射
   - 在 `item.json` 中添加配置

5. **更新工厂类**:
   - 在 `BehaviorFactory.cpp` 中注册事件
   - 在 `SportPlugin` 中注册项目
